## 前言

感觉最近有点沉迷于数据结构无法自拔了喵呜～

**主席树**是**可持久化线段树**的一种，它最大的特点是能够**保存数据结构的每一个历史版本**，这样在我们后续维护的过程中就可以访问之前的信息，查询或基于旧版本继续操作。

## [动态开点线段树](https://www.luogu.com.cn/problem/P13825)

当一个序列 $n\le 10^5$ 的时候可以使用普通的线段树进行操作，但是如果 $n$ 来到了 $10^9$ 这个数量级这样做就无疑会 $MLE$，而如果 $n$ 很大但是被操作的点数目比较少的话，我们就可以采用动态开点的策略，也就是改谁的时候谁没有创建就创建谁，这样就能节省内存了。

但是这样我们就不能用 `p<<1` 和 `p<<1|1` 来维护子树了，需要单独开数组维护，这里为了让结构更清晰我们可以使用结构体。

```c++
struct Node {
    ll sum,lzy; //要维护的信息
    int lc,rc; //左右子树编号
} tree[MAXN];
```

创建节点的时候，我们只需要维护一个全局变量 `tot` 代表当前有多少个节点，然后直接创建节点就行了，接下来的内容按需维护，我这里为了方便学习使用的是例题。

```c++
ll base(int l,int r) {
    return (ll)(l+r)*(r-l+1)/2;
}

int newnode(int l,int r) {
    int p=++tot;
    tree[p].lc=tree[p].rc=0;
    tree[p].tag=0;
    tree[p].sum=base(l,r);
    return p;
}
```

接下来的操作跟普通的线段树就差不多了，只要是我需要这个节点但是这个节点没有就直接新建，下面给出完整代码：

```c++
#include<bits/stdc++.h>
using namespace std;
using ll = unsigned long long;

const int MAXN = 5e6+100;
#define endl '\n'

int tot,n,m,root;

struct Node {
    ll sum,tag; //要维护的信息
    int lc,rc; //左右子树编号
} tree[MAXN];

ll base(int l,int r) {
    return (ll)(l+r)*(r-l+1)/2; //等差数列求和
}

int newnode(int l,int r) {
    int p=++tot;
    tree[p].lc=tree[p].rc=0;
    tree[p].tag=0;
    tree[p].sum=base(l,r);
    return p;
}

void push_up(int p,int l,int r) {
    int mid=l+(r-l)/2;
    ll leftSum=0,rightSum=0;
    if(tree[p].lc) {
        leftSum=tree[tree[p].lc].sum;
    }
    else {
        leftSum=base(l,mid);
    }
    if(tree[p].rc) {
        rightSum=tree[tree[p].rc].sum;
    }
    else {
        rightSum=base(mid+1,r);
    }
    tree[p].sum=tree[p].tag*(r-l+1)+leftSum+rightSum; //标记永久化
}

void update(int &p,int l,int r,int ql,int qr,ll k) { //引用，直接访问内存
    if(!p) p=newnode(l,r);
    if(ql<=l&&qr>=r) {
        tree[p].sum+=k*(r-l+1);
        tree[p].tag+=k;
        return;
    }
    int mid=l+(r-l)/2;
    if(ql<=mid) update(tree[p].lc,l,mid,ql,qr,k);
    if(qr>mid) update(tree[p].rc,mid+1,r,ql,qr,k);
    push_up(p,l,r);
}

ll query(int p,int l,int r,int ql,int qr) {
    if(!p) {
        int L=max(l,ql);
        int R=min(r,qr);
        return base(L,R);
    }
    if(ql<=l&&qr>=r) {
        return tree[p].sum;
    }
    int mid=l+(r-l)/2;
    int L=max(l,ql);
    int R=min(r,qr);
    ll res=tree[p].tag*(R-L+1); //标记永久化，不下传懒标记
    if(ql<=mid) res+=query(tree[p].lc,l,mid,ql,qr);
    if(qr>mid) res+=query(tree[p].rc,mid+1,r,ql,qr);
    return res;
}


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin>>n>>m;
    while(m--) {
        int op;
        cin>>op;
        if(op==1) {
            int l,r,k;
            cin>>l>>r>>k;
            update(root,1,n,l,r,k);
        }
        else {
            int l,r;
            cin>>l>>r;
            cout<<query(root,1,n,l,r)<<endl;
        }
    }
    return 0;
}
```

这棵线段树除了和普通线段树的左右子树区别外，还有个区别就是引入了个技巧：**标记永久化**。

为什么要引入这个技巧呢？因为原本线段树的 `pushdown` 函数默认了左右子树存在，而在动态开点线段树中左右子树有可能是还没有创建出来的，所以我们需要用这个技巧。这个技巧本身其实顾名思义，就是懒标记一直不下传，而是在查询过程叠加贡献。

还有个技巧就是使用了 `l+(r-l)/2` 代替了 `(l+r)>>1`，这是为了防止溢出。

这道题其实为了简化我们的代码量，它有一个 $a_i=i$ 的初始化，那么如果没有这个初始化而是输入 $a_i$ 呢？我们需要改动哪些呢？

答案自然就是我们需要建树，但是 `build(1,1,n)` 就又建满了，这肯定不行。因此我们不需要真的建树，而是用前缀和，前缀最值之类的来帮我们先维护操作前的，然后操作过程中使用 `update` 本身就会慢慢把树建出来。

## 可持久化思想

其实可持久化思想本身并不复杂，它的核心就是：**每次修改了哪些节点就把哪些节点复制下来修改，再和原数据结构共享节点。**

这部分内容在下面的可持久化线段树实现中会具体来讲，这里先不需要了解。

## 权值线段树

**权值线段树**是解决**全局第 $k$ 小**的一种数据结构，它的本质其实是使用线段树维护桶。

给定一个序列，我们要想找到序列中第 $k$ 小的数怎么办呢？一个很简单的做法是使用桶，桶的前缀和显然就是比某某小的数字的个数，于是我们只需要找到第一个桶的前缀和大于等于 $k$ 的数就可以了，这显然可以使用二分答案，非常优美。

但是问题来了，如果带修的话前缀和这个结构就废掉了，那怎么办呢？我们可以把桶维护成一棵线段树：

以序列 `a = [3, 1, 4, 1, 5]` 为例：

```
                    [1,5] sum=5        ← 5 个数总共
                   /            \
              [1,3] sum=3     [4,5] sum=2
              /       \        /      \
         [1,2] sum=2 [3,3]=1  [4,4]=1 [5,5]=1
         /      \
     [1,1]=2  [2,2]=0
```

其实就是用线段树维护 `cnt` 数组，十分优美，接下来利用线段树的区间查询就能快速做了。

**注意：这棵树和普通线段树的写法一模一样，唯一区别是“下标”变成了“值”。**

所以单点修改其实是 `cnt[pos] += 1`。

接下来就是从根节点开始，看左子树（**较小的那半值域**）里面有多少个数字，然后累加一把，过程如下：

```
k=3：
  根 [1,5]：左孩子 [1,3] 有 3 个数
           3 >= 3 → 第 3 小一定在值 ≤ 3 的范围里，走左边

  [1,3]：左孩子 [1,2] 有 2 个数
         2 < 3 → 第 3 小不在 [1,2] 里，走右边
         而且左边这 2 个数已经排前面了，所以在右边它是第 3-2=1 小

  [3,3]：叶子，值是 3 → 答案 3
```

比较好玩的是这个东西似乎还能过掉普通平衡树，但是我懒得玩了。

## [静态区间第 k 小](https://www.luogu.com.cn/problem/P3834)

这个问题经典解法是使用**主席树**，还有一个科技是 **[Wavelet Matrix](https://www.luogu.com.cn/problem/P15107)**，但是这个太难了我不会，感兴趣的可以自行学习喵。

权值线段树确实可以解决第 $k$ 小，但是它只能维护全局带修第 $k$ 小，没办法区间查询，但是它确实帮我们解决了**多重集第 $k$ 小问题**。

那么如何迁移到求解区间呢？思路非常直接，我们可以**对每个前缀维护一棵权值线段树**。

具体来说，我们在学习前缀和的时候就知道一个性质：

$$\sum_{i=l}^{r}a_i=\sum_{i=1}^{r}a_i-\sum_{i=1}^{l-1}a_i$$

我们可以把这个性质迁移过来，维护 $n$ 棵权值线段树就可以区间查询了。

但是很快新的问题就来了：这样的话维护 $n$ 棵线段树妥妥的会 $MLE$，这可太坏了啊！

主席树的关键是：**插入一个新数字 $a_i$，只会让一条从根到叶的路径上的节点变化，路径长度显然为 $\lceil \log_{2}len \rceil$。**

结合到可持久化思想中，我们可以建一个新的版本，新的版本比旧的版本多这么一条链。

新版本不需要复制整棵线段树，只需要做下面的两件事：

- 把这条路径上会经过的节点建出来。
- 其余节点指向旧版本的节点，进行共享。

```
版本 i-1 的树                      版本 i 的树
      root_old                        root_new（新建）
      /      \                        /        \
   left_old  right_old   →      left_new      right_old   ← 右孩子直接复用旧节点！
   ...                              ...
                                  （只有被改的那条链是新的）
```

这样我们 $MLE$ 问题就解决了。

````c++
void update(int &p,int pre,int l,int r,int pos) {
    p=++tot;                      // ① 新建当前节点
    t[p].lc=t[pre].lc;            // ② 先继承旧节点的两个"指针"（默认共享）
    t[p].rc=t[pre].rc;
    t[p].sum=t[pre].sum+1;        // ③ 计数 +1（插入一个数）
    if(l==r) {
        return;
    }
    int mid=l+(r-l)/2;
    if(pos<=mid) update(t[p].lc,t[pre].lc,l,mid,pos);   // ④ 只改一边：把 lc 换成新孩子
    else         update(t[p].rc,t[pre].rc,mid+1,r,pos);
}
````

$rt$ 代表的是版本，$pos$ 其实就是离散化之后的排名，计算方法如下：

```c++
sort(b+1,b+n+1);
int len=unique(b+1,b+n+1)-b-1;                 // 不同的值有几个
for(int i=1;i<=n;i++) {
    int pos=lower_bound(b+1,b+len+1,a[i])-b;    // a[i] 排第几小 → pos
    update(rt[i],rt[i-1],1,len,pos);
}
```

这道题由于不需要区间修改，只是在一个一个插入，所以不需要懒标记，接下来给出完整代码：

```c++
#include<bits/stdc++.h>
using namespace std;

using ll = long long;
const int MAXN = 200005;
const int MAXM = 4500000;
#define endl '\n'

int tot,rt[MAXN];
int n,m,a[MAXN],b[MAXN];

struct Node {
    ll sum;
    int lc,rc;
}tree[MAXM];

void update(int &p,int pre,int l,int r,int pos) {
    p=++tot;
    tree[p].lc=tree[pre].lc;
    tree[p].rc=tree[pre].rc;
    tree[p].sum=tree[pre].sum+1;
    if(l==r) return;
    int mid=l+(r-l)/2;
    if(pos<=mid) {
        update(tree[p].lc,tree[pre].lc,l,mid,pos);
    }
    else {
        update(tree[p].rc,tree[pre].rc,mid+1,r,pos);
    }
}

ll query(int u,int v,int l,int r,int k) {
    //是在一棵虚拟的权值线段树上找第 k 小。这棵虚拟树表示“版本 v 减版本 u”
    if(l==r) return l; //值域大小为 1，就是它了
    int mid=l+(r-l)/2;
    int cnt=tree[tree[v].lc].sum-tree[tree[u].lc].sum; //左边值域有多少个数
    if(cnt>=k) {
        //在左边
        return query(tree[u].lc,tree[v].lc,l,mid,k);
    }
    else {
        //在右边
        return query(tree[u].rc,tree[v].rc,mid+1,r,k);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin>>n>>m;
    for(int i=1;i<=n;i++) {
        cin>>a[i];
        b[i]=a[i];
    }
    sort(b+1,b+1+n);
    int len=unique(b+1,b+1+n)-b-1;
    for(int i=1;i<=n;i++) {
        int pos=lower_bound(b+1,b+1+len,a[i])-b;
        update(rt[i],rt[i-1],1,len,pos);
    }
    while(m--) {
        int l,r,k;
        cin>>l>>r>>k;
        int id=query(rt[l-1],rt[r],1,len,k);
        cout<<b[id]<<endl;
    }
    return 0;
}
```

## [奶龙可比爱 ll](https://code.sipc115.com/problem/666)

> 这道题正解应该是树状数组+倍增法，但是可以用主席树瞎搞，所以贴出来。

有个显然的倒着贪心，时间复杂度 $O(n^2)$。

```c++
#include<bits/stdc++.h>
using namespace std;
int main() {
    int n;
    cin>>n;
    vector<int> a(n+1);
    set<int> s;
    for(int i=1;i<=n;i++) {
        cin>>a[i];
    }
    vector<int> ans(n+1);
    vector<bool> used(n+1,0);
    for(int i=n;i>=1;i--) {
        int cnt=0;
        if(a[i]==0) {
            for(int j=0;j<n;j++) {
                if(!used[j]) {
                    used[j]=true;
                    ans[i]=j;
                    break;
                }
            }
        }
        else {
            for(int j=0;j<n;j++) {
                if(!used[j]) cnt++;
                if(cnt==a[i]+1) {
                    ans[i]=j;
                    used[j]=true;
                    break;
                }
            }
        }
    }
    for(int i=1;i<=n;i++) {
        cout<<ans[i]<<" ";
    }
    return 0;
}
```

然后简单分析一下，发现：

```c++
for(int j=0;j<n;j++) {
    if(!used[j]) {
        used[j]=true;
        ans[i]=j;
        break;
    }
}
```

本质上就是在找全局没有使用过的第 k 小，直接主席树维护：

```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;
const int MAXN = 1e5+100;
const int MAXM = MAXN*21;
#define endl '\n'
#define int long long

int lc[MAXM],rc[MAXM],sum[MAXM],rt[MAXN],a[MAXN],ans[MAXN];
int n,tot;

void build(int &p,int l,int r){
    p=++tot;sum[p]=r-l+1;
    if(l==r)return;
    int mid=(l+r)>>1;
    build(lc[p],l,mid);build(rc[p],mid+1,r);
}

void update(int &p,int pre,int l,int r,int pos,int v){
    p=++tot;lc[p]=lc[pre];rc[p]=rc[pre];sum[p]=sum[pre]+v;
    if(l==r)return;
    int mid=(l+r)>>1;
    if(pos<=mid)update(lc[p],lc[pre],l,mid,pos,v);
    else update(rc[p],rc[pre],mid+1,r,pos,v);
}

int query(int p,int l,int r,int k){
    if(l==r)return l;
    int mid=(l+r)>>1;
    if(sum[lc[p]]>=k)return query(lc[p],l,mid,k);
    return query(rc[p],mid+1,r,k-sum[lc[p]]);
}

void solve(){
    cin>>n;
    for(int i=1;i<=n;i++)cin>>a[i];
    build(rt[n+1],1,n);
    for(int i=n;i>=1;i--){
        int v=query(rt[i+1],1,n,a[i]+1);
        ans[i]=v-1;
        update(rt[i],rt[i+1],1,n,v,-1);
    }
    for(int i=1;i<=n;i++) cout<<ans[i]<<" ";
    cout<<endl;
}

signed main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    solve();
    return 0;
}
```

这份代码的线段树维护的是值域，`sum[p]` 表示的是这段值域内有多少个数还没使用，`build` 里面直接进行 `sum[p]=r-l+1` 等价于普通线段树的初始化。`rt[n+1]` 是初始全未使用，`rt[i]` 表示处理完位置 $i$ 到 $n$ 之后的状态。因为每步只删一个值，所以 `update` 就是标准单点修改。

当然这样做其实是常数爆炸的，实际上只使用权值线段树就足够解决这个问题了，因为维护的是全局信息。关于树状数组倍增的做法以后应该也会学学吧。
