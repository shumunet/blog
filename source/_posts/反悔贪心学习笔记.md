## 前言

反悔贪心是贪心的一种基本思想，核心思想是先做当前最好的选择，之后发现不合适（有冲突）的时候就撤销之前做出的选择，并且以最小的代价进行调整。

## Kevin逛超市 2 (困难版本)            

### 题意简述

有 $n$ 件商品，第 $i$ 件价格为 $p_i$。你有 $a$ 张折扣券和 $b$ 张立减券，分别可以将一件商品的价格变为原价的 $x%$，或减少 $y$（最低为 $0$）。

每件商品最多使用一张券，券可以不用，求买下所有商品的最小总花费。

数据范围：$n\le 2\times10^5$，$0\le a,b\le n$，$1\le x\le99$，$1\le p_i,y\le10^4$；多组测试数据，$\sum n\le2\times10^5$。

### 题解

通过观察题目，我们可以注意到一个性质：**我们应该把优惠券给原价高的商品花**。

原因是给原价低的商品花，有可能减去的会亏（比如说给一个便宜的用立减券会亏，而给便宜的用折扣券也一定没有给贵重的用折扣券减的多）。

所以我们就先排序，排序后想想怎么给那些应该用优惠券的商品用优惠券。

注意到 $n$ 的范围要求我们总时间复杂度应该是 $O(n \log n)$，所以三维动态规划之类的肯定就不想了。

这里就要用到反悔贪心了：**我们让这些商品都先用便宜最多的券，如果后面发现券用多了再把用多的券中换成另外一种券的代价最小的给换过去**。

那么怎么维护用多的券中换成另外一种券的代价最小的商品呢？这里我们可以使用**小根堆**来动态维护。

```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

bool cmp(ll a, ll b) {
    return a > b;
}

void solve() {
    ll n, a, b, x, y;
    cin >> n >> a >> b >> x >> y;
    vector<ll> p(n, 0);
    for (int i = 0; i < n; i++) {
        cin >> p[i];
        p[i] *= 100;
    }
    sort(p.begin(), p.end(), cmp);
    priority_queue<int, vector<int>, greater<int>> q1, q2;
    ll res = 0;
    ll m = min(n, a + b);
    ll cnt = 0;
    for (int i = 0; i < m; i++) {
        ll np1 = p[i] * (100 - x) / 100;
        ll np2 = min(p[i], y * 100);
        if (np2 >= np1) {
            res += np2;
            cnt++;
            q2.push(np2 - np1);
        } else {
            res += np1;
            q1.push(np1 - np2);
        }
    }
    if (cnt > b) {
        while (cnt > b) {
            cnt--;
            res -= q2.top();
            q2.pop();
        }
    } else {
        while (m - cnt > a) {
            cnt++;
            res -= q1.top();
            q1.pop();
        }
    }
    ll sum = 0;
    for (int i = 0; i < n; i++) sum += p[i];
    printf("%.7f\n", ((sum - res) / 100.00));
}

int main() {
    int T;
    cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```

## P3545 [POI 2012] HUR-Warehouse Store

### 题意简述

现在有 $n$ 天。第 $i$ 天上午会进货 $A_i$ 件商品，中午的时候会有顾客需要购买 $B_i$ 件商品，可以选择满足顾客的要求，或是无视掉他。

如果要满足顾客的需求，就必须要有足够的库存。问最多能够满足多少个顾客的需求。

$1\leqslant n\leqslant 2.5\times 10^5$，$0\leqslant a_i,b_i \leqslant 10^9$。

### 题解

显然，我们直接贪心，只要能满足就满足是一定不对的。只要前面有一个顾客要了巨量的东西导致后面的顾客没法买就不行了。

我们改造这个贪心，进行反悔贪心，如果某个顾客没办法买，就去前面找有没有人要了比他更多的东西，让那个人走，换成这个人，这样满足的人数不变，剩下的东西却变多了，后面能买的顾客也就变多了。

显然，我们让要东西最多的人走是最好的，这个东西同样需要动态维护，使用大根堆就行了，和刚刚那道题本质是一样的。

```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;
const int MOD = 1e9 + 7;
const ll INF = 4e18;
const int MAXN = 2e5+100;
#define endl '\n'
#define int long long

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin>>n;
    vector<int>a(n,0);
    vector<int>b(n,0);
    for(int i=0;i<n;i++) {
        cin>>a[i];
    }
    for(int i=0;i<n;i++) {
        cin>>b[i];
    }
    priority_queue<pair<int,int>> que;
    int sum=0;
    for(int i=0;i<n;i++) {
        sum+=a[i];
        if(sum>=b[i]) {
            que.push({b[i],i+1});
            sum-=b[i];
        }
        else {
            if(que.empty()) continue;
            if(que.top().first>b[i]) {
                sum+=que.top().first;
                que.pop();
                que.push({b[i],i+1});
                sum-=b[i];
            }
        }
    }
    cout<<que.size()<<endl;
    while(!que.empty()) {
        cout<<que.top().second<<" ";
        que.pop();
    }
    return 0;
}

```
