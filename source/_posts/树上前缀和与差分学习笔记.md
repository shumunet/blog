## 前言

最近经常开到一些树上问题，所以还是决定学习一下解决树上问题，听学长说树上前缀和与差分是一个比较值得入门的内容，严肃学习了喵。

## 树上前缀和

### 点权情况

树上前缀和的定义是：从根节点出发，到某个节点 $x$ 的路径上，所有权值的总和。

设树以 $1$ 为根，节点 $x$ 的权值为 $a_x$，定义：

> $pre_x = 从根节点到 x 的路径上，所有权值的总和。$

```
        1(3)
       /   \
    2(5)   3(4)
    /
  4(7)
```

那么就有：$pre_1=3,pre_2=8,pre_3=7,pre4=15$，它的本质就是前缀和在树上的推广。

回顾在数组上的运用前缀和快速求区间和，公式如下：

$$sum(l,r)=pre[r]-pre[l-1]$$

树上前缀和也是同样的思想，但是树上的两个节点未必是从同一条路径下来的，这就要运用 LCA 来处理。

例如我们要查询 $u -> v$ 上的节点权值和，那么我们令 $w=LCA(u,v)$，从根到 $u$ 的权值和是 $pre_u$ ，从根到 $v$ 的权值和是 $pre_v$，这棵树可以抽象成下面的形状：

```
        根
         |
        ...
         |
         w
        / \
      ... ...
       u   v
```

显然，用 $pre_u+pre_v$ 的话会导致根到 $w$ 的部分被计算两次，所以我们需要减去，而 $w$ 本身同样被计算了两次，但是减去 $pre_w$ 后就没了，还得再加回来。所以权值和为：

$$sum(u,v)=pre_u+pre_v-2pre_w+a_w$$

### 边权情况

如果权值在边上，而不是在节点上，那么我们可以定义：

$$pre_x=从根到 x 的所有边权之和$$

例如：

```
        1
       / \
    2(5)  3(4)
    |
   4(7)
```

则 $pre_1=0，pre_2=5,pre_3=4,pre_4=13$，上面括号里的数字表示父子边的权值。

查询边路径 $u -> v$ 的时候，LCA 的那条进入节点 $w$ 的边不应该被重新计算，所以公式是：

$$sum(u,v)=pre_u+pre_v-2pre_w$$

### 代码实现

直接使用搜索就可以预处理。如果权值在节点上：

```c++
void dfs(int x, int fa) {
    for (int y : graph[x]) {
        if (y == fa) continue;

        pre[y] = pre[x] + value[y];
        dfs(y, x);
    }
}
```

注意要初始化：

```c++
pre[1] = value[1];
dfs(1, 0);
```

如果权值在边上：

```c++
void dfs(int x, int fa) {
    for (auto [y, w] : graph[x]) {
        if (y == fa) continue;

        pre[y] = pre[x] + w;
        dfs(y, x);
    }
}
```

同样要注意初始化：

```c++
pre[1] = 0;
```

### [例题：[AHOI2008] 紧急集合 / 聚会](https://www.luogu.com.cn/problem/P4281)

这是一棵无根树，我们可以默认 $1$ 是根节点，而问题是求一个点，让 $3$ 个点到它的距离之和最小。

根据题意，我们可以维护树上前缀和，用树上前缀和来维护距离：

$$dist(u,v)=pre_u+pre_v-2pre_{lca(u,v)}$$

显然，这个点只有可能是 $LCA$ 上的点，那么 $3$ 个点有 $3$ 个 $LCA$，简单画图发现深度最深的就是答案的点。

```c++
#include<bits/stdc++.h>
using namespace std;
const int MAXN = 5e5+100;
const int LOG = 31;
#define endl '\n'

int pre[MAXN],n,m,dep[MAXN],p[MAXN][32];
vector<int> edge[MAXN];

void dfs(int u,int fa) {
    p[u][0]=fa;
    for(int v:edge[u]) {
        if(v==fa) continue;
        pre[v]=pre[u]+1;
        dfs(v,u);
    }
}

int lca(int u,int v) {
    if(dep[u]>dep[v]) swap(u,v);
    for(int i=LOG;i>=0;i--) {
        if(dep[p[v][i]]>=dep[u]) v=p[v][i];
    }
    if(u==v) return u;
    for(int i=LOG;i>=0;i--) {
        if(p[u][i]!=p[v][i]) {
            u=p[u][i];
            v=p[v][i];
        }
    }
    return p[u][0];
}

int dist(int u,int v) {
    return pre[u]+pre[v]-2*pre[lca(u,v)];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin>>n>>m;
    for(int i=1;i<n;i++) {
        int u,v;
        cin>>u>>v;
        edge[u].push_back(v);
        edge[v].push_back(u);
    }
    dfs(1,0);
    queue<int>que;
    que.push(1);
    dep[1]=1;
    while(!que.empty()) {
        int u=que.front();
        que.pop();
        for(int v:edge[u]) {
            if(dep[v]) continue;
            dep[v]=dep[u]+1;
            p[v][0]=u;
            for(int j=1;j<=LOG;j++) {
                p[v][j]=p[p[v][j-1]][j-1];
            }
            que.push(v);
        }
    }
    for(int i=1;i<=m;i++) {
        int a,b,c;
        cin>>a>>b>>c;
        int x=lca(a,b),y=lca(a,c),z=lca(b,c);
        int t=x;
        if(dep[y]>dep[t]) t=y;
        if(dep[z]>dep[t]) t=z;
        int ans=dist(a,t)+dist(b,t)+dist(c,t);
        cout<<t<<" "<<ans<<endl;
    }
    return 0;
}
```

## 树上差分

### 点权情况

我们回顾一下数组上的差分，每次只在几个节点上打标记，所有操作完成后再处理前缀和得到结果。

树上差分也是类似的思想：每次只在几个节点上打标记，所有操作完成后，再通过一次 DFS 还原每个节点或边的增量。

树上没有统一的左右顺序，所以这里换一种还原方式：**把每个子节点的差分值加到父节点上**。

假设要让 $u -> v$ 上的每个点都增加 $1$，那么令 $w=LCA(u,v)$。

路径同样可以抽象成下面的形状：

```
        根
         |
        ...
         |
         w
        / \
      ... ...
       u   v
```

考虑在两个端点先打上标记，也就是：

$$ d_u\gets d_u+1,\qquad d_v\gets d_v+1 $$

由于还原时贡献会从子节点向父节点传递，在 $u$ 上打一个 $+1$ 标记，就会让 $u$ 和它的所有祖先得到 $+1$。在 $v$ 上打标记同理。

这样会出现下面的三种情况：

- 从 $u、v$ 向上到 $w$ 的部分变化 $+1$
- 节点 $w$ 同时收到两次 $+1$，变化是 $+2$
- $w$ 上方的祖先同理 也是 $+2$

但目标只有让路径上的变化得到 $+1$，路径外的点应该是无变化的，所以我们需要用类似数组差分的思想去抵消掉多出来的部分。

在 $w$ 上打一个 $-1$ 标记，这个标记会影响 $w$ 的所有祖先，于是 $w$ 的贡献变成 $+1$，而它的祖先得到的标记也是 $+1$。但是它的祖先显然是不应该得到标记的，所以我们只需要给 $w$ 的父亲也打一个 $-1$ 的标记就解决了。因此，点差分公式就出来了：

$$ \begin{aligned} d_u&\gets d_u+1\\ d_v&\gets d_v+1\\ d_w&\gets d_w-1\\ d_{\operatorname{fa}(w)}&\gets d_{\operatorname{fa}(w)}-1 \end{aligned}  $$

### 边权情况

边权差分其实和刚刚讲树上前缀和边权情况是差不多的，如果要让 $u -> v$路径上的所有边都 $+1$，那么仍然令 $w=LCA(u,v)$：

$$d[u]++,d[v]++,d[w]-=2$$

这里边权差分与点权差分的差异和边权前缀和与点权前缀和的差异是一样的，都是因为不能重复计算进入 $w$ 的那条边。

### 代码实现

DFS 回溯时，把子节点的差分值加到父节点：

```c++
void dfs(int x, int fa) {
    for (int y : graph[x]) {
        if (y == fa) continue;
        dfs(y, x);
        d[x] += d[y];
    }
}
```

### [例题：Max Flow P](https://www.luogu.com.cn/problem/P3128)

几乎就是点差分的模板题了，直接写一发就过了。

```c++
#include<bits/stdc++.h>
using namespace std;
const int MAXN = 2e5+100;
const int LOG = 31;
#define endl '\n'

int n,k,p[MAXN][32],dep[MAXN],d[MAXN];
vector<int> edge[MAXN];

int lca(int u,int v) {
    if(dep[u]>dep[v]) swap(u,v);
    for(int i=LOG;i>=0;i--) {
        if(dep[p[v][i]]>=dep[u]) v=p[v][i]; 
    }
    if(u==v) return u;
    for(int i=LOG;i>=0;i--) {
        if(p[u][i]!=p[v][i]) {
            u=p[u][i];
            v=p[v][i];
        }
    }
    return p[u][0];
}

void dfs(int u,int fa) {
    for(int v:edge[u]) {
        if(v==fa) continue;
        dfs(v,u);
        d[u]+=d[v];
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin>>n>>k;
    for(int i=1;i<n;i++) {
        int u,v;
        cin>>u>>v;
        edge[u].push_back(v);
        edge[v].push_back(u);
    }
    queue<int> que;
    que.push(1);
    dep[1]=1;
    while(!que.empty()) {
        int u=que.front();
        que.pop();
        for(int v:edge[u]) {
            if(dep[v]) continue;
            p[v][0]=u;
            dep[v]=dep[u]+1;
            for(int j=1;j<=LOG;j++) {
                p[v][j]=p[p[v][j-1]][j-1];
            }
            que.push(v);
        }
    }
    for(int i=1;i<=k;i++) {
        int s,t;
        cin>>s>>t;
        d[s]++;
        d[t]++;
        int w=lca(s,t);
        d[w]--;
        d[p[w][0]]--;
    }
    dfs(1,0);
    int ans=-0x7f7f7f7f;
    for(int i=1;i<=n;i++) {
        ans=max(ans,d[i]);
    }
    cout<<ans;
    return 0;
}
```

树上前缀和与树上差分是解决离线树上问题的好工具，但是如果在线的话我们就不能使用他们了，而是要就要用到树链剖分等进阶技巧了，应该以后也会单独围绕树链剖分写一篇博客，敬请期待。
