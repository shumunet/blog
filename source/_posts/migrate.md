## 前言

虽然来到了 T3 这个位置大概率不是我能做出来的题了，但是听到他们说这道题区分度比较随机，所以还是决定大概看一看，结果没想到看一眼题解就学会了喵，于是写一篇超详细题解加深我对这道题的理解。

## 题意简述

可以直接看 [题目连接](https://www.luogu.com.cn/problem/P17833)。

数轴上一共有 $n$ 个岛，坐标严格递增。距离 $\le d$ 的两岛之间可以直接飞。对 $u<v$，如果 $u \rightarrow v$ 的最短路**恰好为两条**，那么称 $(u,v)$ 为双径岛屿对，求双径岛屿对的个数。测试点如下：

|  测试点编号  |     $N \le$     | 特殊性质 |
| :----------: | :-------------: | :------: |
|    $1,2$     |       $9$       |    无    |
|  $3 \sim 6$  |      $300$      |    无    |
| $7 \sim 10$  |     $5000$      |    无    |
|   $11,12$    | $2 \times 10^6$ |    A     |
|   $13,14$    | $2 \times 10^6$ |    B     |
| $15 \sim 18$ |     $10^6$      |    C     |
| $19 \sim 21$ | $2 \times 10^5$ |    无    |
| $22 \sim 25$ | $2 \times 10^6$ |    无    |

特殊性质 A：$x_1,x_2,\ldots,x_n$ 构成等差数列。

特殊性质 B：存在一座岛屿，使得海鸟可以从该岛屿直接飞到任意其他岛屿。

特殊性质 C：$x_n-x_1 \le 10d$。

## 暴力 DFS

> 期望得分 $8pts$

当 $n \le 9$ 的时候，显然可以枚举每一对 $(u,v)$，用 DFS 搜一遍所有不重复经过重复岛屿的路径，记录最短长度和最短路的条数，如果最短路的条数是 $2$ 就计数。

```c++
void dfs(int p,int v,int len) {
    //p -> 当前所在的岛
    //v -> 目标岛
    //len -> 从起点到 p 的飞行次数
    if(len>best) return;
    if(p==v) {
        if(len<best) best=len,cnt=1;
        else cnt++;
        return;
    }
    for(int q=1;q<=n;q++) {
        if(!vis[q]&&adj(p,q)) { // adj函数返回能否直接飞
            vis[q]=true;
            dfs(q,v,len+1);
            vis[q]=false;
        }
    }
}
```

## BFS 最短路计数

> 期望得分 $24pts$

这道题我们只关心最短路的条数，所以不需要把每条路都列出来，只需要用 BFS 按层扩展，定义 $way_r$ 为所有满足 $dist_p+1=dist_r$ 的邻居 $p$ 的 $way_p$ 之和，用最短路计数的方式就做完了。

真的做完了吗？容易注意到 $way$ 数组在后面很容易就溢出了，为了避免这个问题，考虑到我们只关心是否恰好最短路为 $2$ 条，我们直接**对 3 取 min**就解决了这个问题。

```c++
dist[u]=0,ways[u]=1,q.push(u);
while(!q.empty()) {
    int p=q.front();
    q.pop();
    for(int r=1;r<=n;r++) {
        if(r==p||gap(p,r)>d) continue; //gap 函数返回的是距离
        if(dist[r]==-1) {
            dist[r]=dist[p]+1;
            ways[r]=ways[p];
            q.push(r);
        }
        else if(dist[r]==dist[p]+1) {
            ways[r]=min(3,ways[p]+ways[r]);
        }
    }
}
```

这样的话我们对每个起点 BFS，总 $O(n^3)$，是可以通过 $N \le 300$ 的。

## 进一步探究最短路的结构

> 期望得分 $40pts$

到这里我们已经完成了所有暴力部分，接下来就需要开始观察一些性质了。

### 引理 1

> 最短路有没有可能先往北飞再往南飞？

没有可能，证明也几乎不用证，想一想就能想出来了喵。

### 引理 2

> 考虑从 $u$ 出发，最多飞 $k$ 次，最远能到达哪个岛?

我们定义 $nxt_i$ 表示 $i$ 一次能到的最远岛，令 $R_0=u,R_k=nxt_{R_{k-1}}$。到 $u$ 距离恰好为 $k$ 的岛正好是 $(R_{k-1},R_k]$，我们称为第 $k$ 层。

这里对第 $k$ 层的定义就是：飞 $k$ 次才能第一次到达的岛的集合。

飞 $k-1$ 次能到的最右的点就是 $R_{k-1}$，再飞一次到达最远处 $R_k$，而 $(R_{k-1},R_k]$ 中的每个点都和 $R_{k-1}$ 相邻（区间性，可以一步到达），所以距离 $\le k$，它们又都在 $R_{k-1}$ 右边，所以说距离又有 $> k-1$，由此可以推出最多飞 $k$ 次能到的最远的岛就是 $R_k$。

### 引理 3

> 如果 $v$ 在 $k+1$ 层，它在最短路上的前一个岛可能是谁？

定义 $prv_i$ 表示能一步到达 $i$ 的最左边的岛。

前驱必须在第 $k$ 层与 $v$ 相邻，否则就不能一步到达了。与 $v$ 相邻的左边岛是 $[pre_v,v)$，这些都是能一步到达的。

$R_{k-1}$ 是够不着 $v$ 的，否则 $R_{k-1}$ 就在第 $k$ 层了。

由此我们可以得出：$prv_v>R_{k-1}$，简单取个交集就能得到前缀集合是 $[prv_v,R_k]$，这显然是 $k$ 层的一个后缀。

### 算法

根据我们刚刚推出的引理，我们可以固定起点 $u$，然后逐层计算，层内逐点计算：

$$ways_v=min(3,\sum_{w=prv_v}^{R_k}ways_w)$$

原理也是很简单的，因为 $[pre_v,R_k]$ 中的点都是可以一步到达 $v$ 的（根据引理），那么直接计算贡献就行了。

对于后面那一坨求和，显然可以维护 $ways$ 数组的前缀和 $pre$ 数组来实现 $O(1)$ 计算，这样的话每次处理 $O(n)$，共计 $n$ 个点，总时间复杂度就来到了 $O(n^2)$，足够得到 $40pts$。

```c++
for(int u=1;u<=n;u++) {
    ways[u]=1,pre[u-1]=0,pre[u]=1;
    int R=u;
    while(nxt[R]>R) {
        int nr=nxt[R];
        for(int v=R+1,v<=nr;v++) {
            int L=max(pre[v],u);
            ways[v]=min(3LL,pre[R]-pre[L-1]);
            pre[v]=pre[v-1]+ways[v];
            if(ways[v]==2) ans++;
        }
        R=nr;
    }
}
```

对于 $nxt$ 和 $prv$ 数组，我们可以使用双指针 $O(n)$ 预处理，接下来每次查询就是 $O(1)$ 了。

## 特殊性质 C

> 期望得分 $76pts$

简单说一下特殊性质 A 因为是等差数列，容易推导出来一个下标差的关系。

特殊性质 B 就是中心岛，分类讨论一下就完了。

由于特殊性质 A 和 B 都属于对正解无关的特殊性质，我们这里直接讲特殊性质 C。

$x_n-x_1\le10d$ 能说明什么呢？

显然，最短路上相隔两步的岛一定不相邻（不然就不符合定义了），也就是说：

$$x_{R_k+1}-x_{R_k-1}>d$$

那么每跨越两层，下标至少会前进 $d$。但是这组测试点因为 $N$ 超级大，我们需要一个线性的做法，而根据我们刚刚的式子容易发现层数不会超过 $20$，那么这组测试点就应该是大常数的线性复杂度。

接下来我们进行一些观察：

> 同一层里越靠右的点，前驱后缀(前驱指的是上一层的点) $[prv_v,R_k]$ 是越短的，因为 $prv$ 数组是单调的，所以 $ways$ 随着下标增长一定是单调不增的，层内最右点 $R$ 的 $ways$ 最小。

> 下一层每个点都和 $R$ 相邻，所以下一层所有点最短路条数都大于等于 $ways_R$，于是一旦有一层 $ways$ 大于等于 $3$ 了，后面每一层都大于等于 $3$。

根据这些观察，我们可以发现只需要看最后三个点就够了，因为在算下一层的时候每个点只用关心上一层的尾巴。

下一层的点是 $[R,NR]$，其中 $NR=nxt_R$，那么对于下一层的任何一个点 $w$，它的最短路条数都是上一层能飞到 $w$ 的点的 $ways$ 总和。而这个集合一定是上一层的一个后缀，右端点固定 $R$，左端点是 $prv_w$，那么 $w$ 只要是能连到 $R-2$，它就能连到 $R$、$R-1$、$R-2$ 三个点，这样的话它的最短路条数就一定超过 $2$ 了，这不符合题意。

因此我们定义状态 $(R,a,b,c)$，其中 $c=min(3,ways_R)$，$b=min(2,ways_{R-1})$，$a=[R-2]在本层$。

起点状态是 $(u,0,0,1)$，在转移过程中出现 $NR=R$ 或者 $c$ 转移后大于等于 $3$ 就停止。

## 最终观察

> 期望得分 $100pts$

两个不同的起点，长链上从任何 $u \le R$ 出发都会走到同一个状态 $(R,0,0,1)$，而且后面的转移只用到了 $R,a,b,c,nxt$，与起点是无关的，所以后面的过程都跟起点 $u$ 无关。

于是我们只需要定义 $f(R,a,b,c)$ 是从这个状态往后所有层 $ways=2$ 的点数之和，那么有：

$$f(R,a,b,c)=本层贡献+f(新状态)$$

于是答案就是 $\sum_{u=1}^{n} f(u,0,0,1)$

至此，我们实现了一个常数很小的线性做法，总时间复杂度 $O(n)$，足够我们通过本题了。

```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;
const int MAXN = 2e6+100;
const ll INF = 4e18;
#define endl '\n'

ll n,d,x[MAXN],nxt[MAXN],f[MAXN][2][3][2];

void solve() {
    //输入
    cin>>n>>d;
    for(int i=1;i<=n;i++) cin>>x[i];
    //双指针求 nxt
    for(int i=n,r=n;i>=1;i--) {
        while(x[r]-x[i]>d) r--;
        nxt[i]=r;
    }
    // 按 R 从大到小递推
    for(int R=n;R>=1;R--) {
        for(int a=0;a<2;a++) {
            for(int b=0;b<3;b++) {
                for(int c=1;c<=2;c++) {
                    f[R][a][b][c-1]=0;
                    if((a&&R<3)||(b&&R<2)||(a&&!b)) continue; //不合法
                    int NR=nxt[R];
                    if(NR==R) continue; //下一层是空的了
                    // b=0 a=0 表示那个点不在本层，退化成 R（连不到任何东西）
                    int nb=R;
                    if(b) nb=nxt[R-1];
                    int na=R;
                    if(a) na=nxt[R-2];
                    //下一层三段：(R,na] >=3、(na,nb] = c+b、(nb,NR] = c
                    if(c==2) f[R][a][b][c-1]+=NR-nb;
                    else if(b==1) f[R][a][b][c-1]+=nb-na;
                    int nc=c;
                    if(b&&nb>=NR) nc+=b;
                    if(a&&na>=NR) nc++;
                    if(nc>3) nc=3;
                    int nbv=0;
                    if(NR-1>R) {
                        nbv=c;
                        if(b&&nb>=NR-1) nbv+=b;
                        if(a&&na>=NR-1) nbv+=1;
                        if(nbv>2) nbv=2;
                    }
                    int nav=0;
                    if(NR-2>R) nav=1;
                    if(nc<3) f[R][a][b][c-1]+=f[NR][nav][nbv][nc-1];
                }
            }
        }
    }
    ll ans=0;
    for(int u=1;u<=n;u++) {
        ans+=f[u][0][0][0];
    }
    cout<<ans<<endl;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T = 1,c;
    cin>>c>>T;
    while (T--) {
        solve();
    }
    return 0;
}
```
