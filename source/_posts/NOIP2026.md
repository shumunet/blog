## [[NOIP2026] 和弦 / chord](https://www.luogu.com.cn/problem/P18115)

> 难度：**普及+/提高−**

不妨设 $a \ge b$，容易注意到 $a=b$ 的时候答案就是 $a$。特殊性质一直在提示我们跟 $a-b$ 的数值是有关的，这里设 $d=a-b$。

这个差显然是与 $x$ 无关的，因为最后是 $(a+x)-(b+x)=a-b$。

这样的话，问题就变成了：选一个 $A \ge a$，令 $B=A+d$，最小化 $lcm(A, B)$。

为了方便继续推，我们设 $A=a+x$ ， $B=b+x$。

令 $g=gcd(A,B)$，那么有 $g \mid A$ 和 $g \mid B$，因此推出 $g \mid (B-A)$。也就是说，$d$ 一定是 $g$ 的倍数，即 $g \mid d$。

根据 $lcm(A,B)=\frac{A \cdot B}{gcd(A,B)}$，要想最小化结果，就要让 $gcd(A,B)$ 大。而 $gcd(A,B)$ 又一定是 $d$ 的一个约数，所以我们可以枚举 $d$ 的每个约数 $g$ ，假设 $gcd(A,B)=g$，然后不断更新答案。

具体来说，因为 $B$ 是 $g$ 的倍数，设 $B=gk$，同理设 $d=gm$，那么 $A=gm+gk=(k+m)g$，我们又希望 $g$ 必须恰好为 $gcd(A,B)$，所以有 $gcd(k,m)=1$，在这种情况下有 $lcm(A,B)=\frac{A \cdot B}{g}=\frac{(k+m)g \cdot gk}{g}=(k+m)gk$。

根据以上推理，我们在枚举 $g$ 的过程中，因为 $d=gm$，所以 $m=\frac{d}{g}$，因此我们不知道的只有 $k$。而我们要的是最小化 $lcm(A,B)$，所以我们要让 $k$ 尽可能小，因为这是一个单调递增的式子。

因为 $B \ge b$，所以说 $gk \ge b$，也就是说 $k \ge \frac{b}{g}$，因此 $k$ 的下限是 $k=\lceil b/g\rceil$，上面又要求了 $gcd(k,m)=1$，所以我们完全可以暴力计算出 $k$ 的最小值，然后答案就是目前答案与 $(k+m)gk$ 取最小值。

```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;
const ll INF = 4e18;
#define endl '\n'

ll gcd(ll a,ll b) {
    if(b==0) return a;
    return gcd(b,a%b);
}

void solve() {
    ll a,b;
    cin>>a>>b;
    if(a<b) swap(a,b);
    if(a==b) {
        cout<<a<<endl;
        return;
    }
    ll d=a-b;
    vector<ll> tmp;
    for(int i=1;i*i<=d;i++) {
        if(d%i==0) {
            tmp.push_back(i);
            if(i*i!=d) tmp.push_back(d/i);
        }
    }
    ll ans=INF;
    for(ll g:tmp) {
        ll m=d/g;
        ll k=(b+g-1)/g;
        while(gcd(k,m)!=1) k++;
        ans=min(ans,g*k*(k+m));
    }
    cout<<ans<<endl;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int c,T = 1;
    cin>>c>>T;
    while (T--) {
        solve();
    }
    return 0;
}
```
